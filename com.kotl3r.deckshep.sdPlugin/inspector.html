Setup and preferences

In each Codex pane, run /title thread-id with an empty composer, then select that agent on the deck. Use only the thread-ID title item. Reapply after a new chat if the title resets. This matches the displayed ID to that pane's Codex daemon; ambiguous or missing IDs disable native controls.

Connect to local Herdr 0.9.5. Type messages in Herdr; draft submission needs cursor support. The plugin does not change your titles, global Codex settings or Herdr's saved session references.

Selection and Next can request a pane. They do not verify keyboard focus or allow typing. Core names are read-only labels, shown only when the core and App agree. Codex controls change the selected chat through its daemon and never type into the terminal. Zoom and terminal input remain unavailable. Plain focus requests also need an approved App build; without one, selection stays on the deck.

Switch between Rex and Herdr using Stream Deck’s profile selector. Connection and consent settings stay with this controller; animation and prompt text are shared. Changes save automatically.

Required for controls. Rex temporarily copies its pane ID; the helper restores your clipboard formats. Rex may show a copy notification. Background status checks do not use the clipboard.

Enable Remote Control in Rex first. Select a ready Codex agent on the deck, then configure its status line once.

Setup opens Codex settings dialogs and saves the session-ID footer. Your process and unsent input stay in place. Leave Rex alone until setup finishes.
