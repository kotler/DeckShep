Setup and preferences

In each Codex pane, run /title thread-id with an empty composer, then select that agent on the deck. Use only the thread-ID title item. Reapply after a new chat if the title resets. This matches the displayed ID to that pane's Codex daemon; ambiguous or missing IDs disable native controls.

Connect to local Herdr 0.9.5. Type messages in Herdr; draft submission needs cursor support. The plugin does not change your titles, global Codex settings or Herdr's saved session references.

Selection and Next can request a pane. They do not verify keyboard focus or allow typing. Core names are read-only labels, shown only when the core and App agree. Codex controls change the selected chat through its daemon and never type into the terminal. Zoom and terminal input remain unavailable. Plain focus requests also need an approved App build; without one, selection stays on the deck.

Switch between Rex and Herdr using Stream Deck’s profile selector. Connection and consent settings stay with this controller; animation and prompt text are shared. Changes save automatically.

Required for controls. Rex temporarily copies its pane ID; the helper restores your clipboard formats. The dot normally follows Rex session focus without copying. Ambiguous session changes and guarded input may show a copy notification.

Enable Remote Control in Rex first. Ready-state Model, Effort, Permissions and Mode use the focused native UI; they do not need a thread ID. Other thread-bound actions require a verified Codex hook binding or the session ID in your own footer.

The check only reads the pane and Codex. DeckShep never changes your status line or sends input.

Claude Code (experimental)

In Rex, Model and Effort cycle the focused native Claude CLI’s picker for this session. Permissions advances its permission mode, including Plan. These three keys use the CLI’s local session registration and default keyboard shortcuts. Interrupt can also use the working CLI and its visible Escape hint. Queue and choice controls require the optional metadata hooks described in docs/CLAUDE.md. Physical validation of the hook-free picker is pending. Herdr submissions remain unavailable.
