Date November 15, 2026.

The owner authorized a live run against test-owned instances to assess Rex-style controls. Native Model delivery succeeded while an owned editor kept keyboard focus. ## Harness compatibility corrections

The first calibration attempt stopped at its command vocabulary check because App 0.1.16 adds the optional focus argument to space.new. A second stopped when the App selected its fallback shell for the unrecognized test-shell name. Both attempts cleaned up and preserved tracked settings. The harness now checks the exact reviewed argument set for each App version and names its compiled fixed-command shim zsh. That shim continues to execute only its allowed fixed test programs.

The harness now selects between the two reviewed candidate report hashes, maps each pair to its source tags, seeds update notes with the selected App version, and serves matching updater metadata. Whole-bundle and peer verification still run on every staged copy. Regression tests cover the new pair, mixed-pair rejection, report substitution and version seeding. The navigation test now retains a sanitized report on failure as well as success.
