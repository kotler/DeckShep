# Rex beta review — Codex and Claude parity

**Decision: parity across the three rows is not yet demonstrated for the 1.4.0 candidate.** Mode is the intended layout exception. Other differences need a verified implementation, a recorded beta limitation, or evidence through the installed key. The clearest product difference is on row 3: a verified hook-free Claude turn can expose Interrupt while leaving Steer and Queue blank. Physical Codex Queue and Steer passed with a session-ID footer. Rows 1 and 2 share their Rex navigation path; the main gaps there are mixed-provider transition evidence.
