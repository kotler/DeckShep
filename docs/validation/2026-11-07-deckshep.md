# DeckShep commercial-preparation checkpoint

November 7, 2026, America/Los_Angeles. Version 1.4.0, private review only.

The owner selected DeckShep, profiles Rex / Herdr, proprietary licensing, and
Everett Kotler as seller. This checkpoint applies those display/brand changes,
adds original key-and-crook artwork, commercial preparation documents and unsent
permission requests, and blocks remote release creation pending recorded reviews.

break key identities. No guard or routing change is intended. Baseline golden
files were not edited.
