Codex app icon
==============

`codex-app.png` is a 128 px copy of `/Applications/ChatGPT.app/Contents/Resources/icon-codex-dark-color.png` from the user’s installed OpenAI app. Used locally to identify live Codex agents. Original artwork belongs to OpenAI; no endorsement is implied. The color and design of that source copy are unchanged.

`codex-mark.png` is a transparent white monochrome derivative used as a low-opacity background watermark. It removes the neutral app tile and retains the Codex flower/terminal mark. It carries the same OpenAI artwork and redistribution limitations.

Lucide control icons
====================

`lucide/` contains unmodified SVGs from `lucide-static@0.468.0`, downloaded from the npm CDN at https://unpkg.com/lucide-static@0.468.0/icons/. Used as one consistent family in the Signal renderer. See `lucide/LICENSE` for the ISC and Feather MIT notices.
